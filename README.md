# Sanyukt Durga Puja Trust, 2026 — Modern Website

This is a static HTML/CSS/JS website.

## Improvements
- Modern responsive festival theme with improved typography and spacing.
- Cleaner sticky navigation with mobile menu and highlighted Donate action.
- Improved hero section, stats, cards, countdown and section hierarchy.
- Responsive schedule, events, donation, previous-year and contact sections.
- Gallery now includes local demo artwork and the existing lightbox.
- No external image hosting is required for the gallery.
- Existing donation QR image is preserved unchanged.

## Replace demo gallery images
The files `assets/gallery-*.svg` are placeholders. Replace them with real JPG/PNG photos and update the `GALLERY` array in `script.js`.

## Run
Open `index.html` directly in a browser or host the folder on any static web host.
